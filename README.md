# Rohan Shrivastava — Engineering Portfolio

A static site (plain HTML + CSS, no build step) hosted on GitHub Pages.
Push to `main` and the site updates in about a minute.

## Folder layout

```
index.html                 Homepage: banner, intro, Guild Record (experience),
                           Quest Log (projects), Chronicles (posts & events), contact
soilnode.html              Soil Node project page
ruhart-lidar-bot.html      RU HART: LiDAR bot
ruhart-motor-driver.html   RU HART extension: motor driver
breathe.html               Breathe.exe project page

css/theme.css              All styling for every page (colors are at the top)
js/main.js                 The "Copy" button next to the email address
assets/hero-scene.svg      Homepage banner (hero from the side)        ┐
assets/project-scene.svg   Project page banner (hero facing forward)   │ generated by
assets/contact-scene.svg   Contact scene on every page (from behind)   │ tools/generate_art.py
assets/starfield.svg       Background star tile                        ┘
tools/generate_art.py      Draws the pixel art (edit this, then run it)
tools/bump_version.py      Makes browsers load fresh CSS/JS/art after a change
media/                     Photos, schematics, and videos, one folder per project
files/                     Downloadable files (resume)
fonts/                     Bundled fonts (Pixelify Sans, Inter)
```

## Common edits

**Change text on a page** – open the page's `.html` file; each section has a
comment above it describing what it is.

**Change colors or fonts** – edit the variables in section 2 of
`css/theme.css` (e.g. `--color-gold`).

**Add a job or internship** – in `index.html`, copy the `<article class="experience panel">`
block inside the GUILD RECORD section and change the role, company, dates, and points.

**Add a LinkedIn post** – in `index.html`, copy one `<article class="post-card panel">`
block in the CHRONICLES section (above the "See All My Posts" card) and change
the link, date, title, excerpt, and image. Get the link from the post's "..."
menu → "Copy link to post". For an event with no post, copy a
`post-card--event` card instead and replace its placeholder with a photo.

**Add a project card** – in `index.html`, copy one `<article class="quest-card panel">`
block inside the Quest Log, change the tag, link, description, image, and skills.
Cards fill a three-column grid in order, so a new card takes the next open spot.

**Add a project page** – copy `soilnode.html`, rename it, change the title and
subtitle in the BANNER block, and swap in your sections. The banner art and
the contact section at the bottom come along automatically. Building blocks you can reuse:

| Layout | Markup |
| --- | --- |
| Image left, text right | `<div class="split">` with `split__media` then `split__text` |
| Text left, image right | `<div class="split split--reverse">` |
| Two images side by side | `<div class="image-pair">` with two `<figure>`s |
| Two images stacked | `<div class="split__media image-stack">` |
| Video | `<video class="video" src="..." controls playsinline>` |

**Update the resume** – replace `files/Rohan_Shrivastava_Resume.pdf` (keep the same name).

**Add the Soil Node demo video** – save it as `media/soilnode/demo.mp4`, then follow
the comment in the Demo section of `soilnode.html`.

## Seeing your changes right away

Browsers keep copies of the CSS, JS, and art for a while. After changing
anything in `css/`, `js/`, or `assets/`, run:

```
python3 tools/bump_version.py
```

It updates the `?v=` tag on every link to those files so visitors get the new
versions immediately. (If you still see an old version, a hard refresh with
Ctrl+Shift+R / Cmd+Shift+R always works.)

## Editing the pixel art

```
python3 tools/generate_art.py
```

The script draws every scene pixel by pixel. The hero has three text sprites
near the top of the file: `HERO_SIDE` (homepage banner), `HERO_FRONT` (project
page banners; only its left half is written, `mirror()` copies it), and
`HERO_BACK` (contact scene). Each letter is a color from `HERO_PALETTE`
(e.g. `A` = steel armor, `C` = violet cape, `H` = hair), so changing a color
there updates him everywhere. Each scene's
layout (horizon, cliff, moon position) is in the constants above its
`build_...()` function. Rerun the script, then `tools/bump_version.py`.

## Contact links

The contact section is the same block at the bottom of every page (search for
CONTACT). "Email Me" opens a Gmail draft addressed to me, "LinkedIn" opens my
profile, and "Copy Email" (next to the typed-out address) copies the address.
